1Purines vs. pyrimidines?
Purines (2 rings): A, G. Pyrimidines (1 ring): C, T.
Also know: nucleotide = phosphate + deoxyribose + base.
2Hydrogen bonds in A–T vs. G–C?
A–T = 2. G–C = 3 (stronger).
3Why is DNA stable if hydrogen bonds are weak?
Billions of them add up.
45′ end vs. 3′ end?
5′ = free phosphate (carbon 5). 3′ = free OH (carbon 3).
Also know: DNA strands are antiparallel.
5Why doesn't the wrong nucleotide get added?
Mismatch = repulsion → bounces off. Right match sticks just long enough to react.
6What drives polymerization?
Cutting off pyrophosphate from the nucleotide triphosphate (the phosphates repel each other → high energy).
7DNA polymerase's 3 limits?
Can't use double-stranded DNA · adds only to the 3′ end · can't start without a primer.
Also know: new DNA is always synthesized 5′→3′; the leading-strand template runs 3′→5′.
8Why are origins A–T rich?
Only 2 hydrogen bonds → easier to pull apart.
9Helicase / topoisomerase / SSB proteins?
Helicase unzips · topoisomerase cuts, unspins supercoils, reseals · SSB (single-strand binding) keeps strands apart.
Order: Origin → Helicase/Topo/SSB → Primase → Polymerase → Ligase.
10Why an RNA primer?
Primase can start from scratch; polymerase can't. RNA is short-lived, so it gets replaced with DNA.
Also know: RNA's extra OH makes it less stable than DNA.
11Leading vs. lagging strand?
Leading: continuous. Lagging: short Okazaki fragments. Both built 5′→3′.
12Who removes primers and seals gaps?
Polymerase exonuclease removes primers; DNA ligase seals.
Primer cleanup: polymerase exonuclease removes the RNA primer; polymerase replaces it with DNA; ligase seals the remaining nick.
13End-replication problem and fix?
End primers lost → chromosomes shorten. Telomerase adds junk (non-coding) repeats so genes aren't lost.
14Why turn telomerase off in mature cells?
Limits division → senescence. Stem cells keep it. Cancer usually turns it back on.
15Why Taq polymerase?
Heat-stable (Thermus aquaticus) — survives 95°C.
PCR tube: sample DNA + nucleotide triphosphates + target-specific primers + Taq + magnesium buffer.
16PCR steps and temps?
Denature 95°C → anneal 50–60°C → extend 72°C. Doubles each cycle.
Also know: typically 30–40 cycles. Heat replaces helicase; primers replace primase; short PCR products do not require ligase.
17What makes PCR specific?
Designed primers bind only the target sequence.
Clinical framing: PCR is used to amplify target DNA for diagnosis. The full guide flags a caveat for non-DNA viruses.
18Low Ct means?
More target DNA.
Ct = cycle threshold: number of cycles needed to cross the fluorescence threshold.
19Why does the curve plateau?
Runs out of nucleotides/primers.

If you remember nothing else

  • A–T = 2 H bonds; G–C = 3; DNA strands are antiparallel.
  • DNA polymerase needs single-stranded template + primer and adds only to the 3′ end.
  • Telomerase is off in mature cells and commonly reactivated in cancer.
  • PCR: 95°C denature → 50–60°C anneal → 72°C extend; low Ct = more starting target DNA.
