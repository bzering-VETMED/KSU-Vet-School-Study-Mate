⚠️ Precision traps

  • Box color = enzyme. Only gastric mucosa + platelets are COX-1 (brown). Every other green box is COX-2.
  • Platelets TxA2 = aggregation + vasoCONSTRICTION · Endothelium PGI2 = platelet resting + vasoDILATION. Opposites.
  • Same PGE2, different tissue: gastric/colon = cytoprotection · joints = inflammation, pain · kidney = afferent arteriole dilation.
  • Leukotrienes (LTB4–LTE4) come from 5-LOX, not COX. Airways = bronchoconstriction + mucus.
  • Uterus = PGF2α → luteolysis (not PGE2).
  • Why it matters (S20–S29): COX-1 block → ulcers · COX-2-selective block → loses endothelial PGI2 but keeps platelet TxA2 → cardiovascular events · any NSAID → less kidney PGE2 → AKI risk.
⚠️ Kidney enzyme: green (COX-2) on S7, but S28 draws PTGS1/2 in the kidney. Answer "COX-2" if asked from this table; know both make kidney PGE2. Confirm with the transcript.
