Two bladder phasesSTORAGE (filling) and VOIDING (emptying / micturition) (S3)
DetrusorSmooth muscle in the bladder wall
Internal vs external urethral sphincterInternal = AUTONOMIC · external = VOLUNTARY (somatic, pudendal nerve) (S3)
★ Storage phase = sympatheticDetrusor RELAXES (β₂/β₃) + internal sphincter CONTRACTS (α₁) · low-pressure filling (S3)
★ Voiding phase = parasympatheticPelvic nerve · detrusor CONTRACTS (M3 muscarinic) + internal sphincter RELAXES · voluntary relaxation of external sphincter (S3)
Beta receptors (second messenger)All Gs → ↑ cyclic AMP → smooth muscle RELAXES
Bladder stretch afferents go to…Pontine micturition center (brainstem) + cerebral cortex (conscious urge) (S4)
Pontine storage centerLow stretch input → sympathetic: inhibits detrusor, tightens sphincter (S4)
Pontine micturition center (Barrington's nucleus)High stretch input → suppresses sympathetic, activates parasympathetic → voiding (S4)
Cystometrogram phase 1Initial pressure rise to the baseline set point (S5)
★ Cystometrogram phase 2"Isobaric" · volume rises, pressure barely changes (detrusor actively relaxing) (S5)
Cystometrogram phase 3Detrusor fully relaxed → pressure rises sharply → urge to void (S5)
Can't relax OR can't contract the detrusorBOTH cause frequent urges to urinate (different causes)
Neurogenic bladderImproper autonomic input after losing the pontine centers (e.g., spinal cord lesion) (S6)
★ Upper motor neuron bladderSpinal lesion → REFLEX / hyperreflexive bladder · overactive detrusor, poor voluntary control (S6)
★ Lower motor neuron bladderSacral lesion → ATONIC bladder · can't contract → retention, overflow (S6)
★ BethanecholM3 (muscarinic) AGONIST → detrusor contracts · for LOWER motor neuron bladder (S6)
★ Phenylpropanolamineα₁ AGONIST → ↑ internal sphincter tone · for incontinence (S6)
★ OxybutyninANTImuscarinic → relaxes an overactive detrusor · urge incontinence (S6)
